# 도시 조사결과 집계 및 미조사 목록 자동화 시스템 (unfi-ing)

수도권 3개 시도(경기도, 서울특별시, 인천광역시)의 표본점 및 조사결과 데이터를 분석하여, 미조사 현황 추출 및 지역별 집계표를 자동으로 생성하는 웹 애플리케이션입니다.

---

## 📌 주요 기능
1. **엑셀 데이터 분석 및 자동 집계**:
   - 표본점 목록과 조사결과표를 비교 분석
   - 시도별/시군구별 조사 진행율 자동 계산 및 백분율 서식 적용
   - 미조사 목록 별도 시트 분리 및 추출
2. **웹 인터페이스 제공 (Flask)**:
   - 파일 업로드 및 실시간 집계 현황 확인
   - 집계 결과 엑셀 파일 즉시 다운로드
3. **간편 실행 지원**:
   - 배치 파일(`웹서버_실행하기.bat`, `실행하기.bat`)을 통한 원클릭 실행

---

## 🚀 실행 방법

### 1. 웹 서버 실행
`웹서버_실행하기.bat` 파일을 더블 클릭하거나 콘솔에서 아래 명령을 실행합니다:
```bash
python app.py
```
실행 후 브라우저에서 `http://127.0.0.1:5000`으로 접속합니다.

### 2. 스크립트 직접 실행
```bash
python generate_mi_list.py
```

---

## 📁 주요 구성 파일
- `app.py`: 웹 서버 구동 및 엑셀 분석 백엔드 로직
- `templates/index.html`: 웹 대시보드 화면
- `generate_mi_list.py`: 미조사 목록 및 집계 생성 독립 실행 스크립트
- `verify_generation.py`: 결과 검증 스크립트
