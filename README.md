# 도시 조사결과 집계 및 미조사 분석 시스템 (unfi-ing) 📊

수도권 3개 시도(경기도, 서울특별시, 인천광역시)의 표본점과 조사결과 데이터를 대조하여, **진행율 계산, 지역별 집계표, 미조사 현황 분석 및 서식이 적용된 엑셀 파일**을 자동 생성하는 인터랙티브 웹 애플리케이션입니다.

---

## 🌟 주요 특징

1. **설치 없는 순수 브라우저 웹앱 (`index.html`)**:
   - 별도의 파이썬 또는 백엔드 서버 설치 없이 브라우저에서 100% 동작합니다.
   - 엑셀 파일을 드래그 앤 드롭하면 즉시 실시간 분석 대시보드가 열립니다.
2. **공식 서식 엑셀 파일 즉시 추출**:
   - **헤더**: 짙은 남색 배경 (`#2F5597`) + 흰색 볼드 텍스트
   - **합계 행**: 전체 합계(블루그레이), 경기도(피치), 서울(스카이블루), 인천(라벤더) 구분 배경색
   - **조사완료(미조사 0건)**: 해당 시군구 행 전체 **빨간색 굵은 글씨 (`#FF0000`, Bold)** 강조
   - **수식 서식**: 진행율 백분율(`0.0%`), 표본 개수 천단위 쉼표(`#,##0`)
3. **로컬 Flask 웹 서버 지원 (`app.py`)**:
   - `웹서버_실행하기.bat`를 더블 클릭하여 로컬 네트워크(스마트폰, 태블릿 등)에서도 접속 가능합니다.

---

## 🚀 사용 방법

### 1. 웹 브라우저에서 바로 사용하기 (가장 간편함)
프로젝트 폴더의 **`index.html`** 파일을 더블 클릭하여 브라우저(크롬, 엣지 등)로 실행합니다.

### 2. GitHub Pages 웹사이트로 접속하기
GitHub 저장소의 Pages 기능이 활성화되어 있으면 언제 어디서나 인터넷 주소로 접속할 수 있습니다:
👉 **[https://hcrfor.github.io/unfi-ing/](https://hcrfor.github.io/unfi-ing/)**

### 3. 로컬 웹 서버로 구동하기
`웹서버_실행하기.bat`를 실행하거나 터미널에서 다음 명령을 실행합니다:
```bash
python app.py
```
접속 주소: `http://127.0.0.1:5000`

---

## 📁 프로젝트 파일 구성

- **`index.html`**: 단독 실행 가능한 브라우저 기반 분석 대시보드 (GitHub Pages 메인)
- **`app.py`**: Flask 기반 로컬 웹 서버 및 백엔드 분석 로직
- **`templates/index.html`**: Flask 웹 서버용 화면 템플릿
- **`generate_mi_list.py`**: 콘솔 독립 실행용 분석 및 엑셀 생성 스크립트
- **`verify_generation.py`**: 결과 검증 스크립트
- **`웹서버_실행하기.bat` / `실행하기.bat`**: 간편 실행 배치 파일
